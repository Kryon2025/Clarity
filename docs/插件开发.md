# 深清插件开发

> 适用：深清 0.1.x ｜ 插件 API 版本 **0.1**
>
> 深清插件是放在插件目录里的普通 Python 目录，由宿主在启动 / 启用时加载，
> 与宿主同进程运行。形态参考 ClassWidgets 2：**目录 + 清单 + 入口类 + 生命周期钩子 + 插件自己的数据**。
> 安装插件 = 信任这份本地 Python 代码，详见「安全提示」。
>
> 完整 SDK 教程与 JSON Schema 见 [sdk/README.md](../sdk/README.md)、
> [sdk/plugin.schema.json](../sdk/plugin.schema.json)；可复制模板在 `templates/basic-plugin`、
> `templates/widget-plugin`。

## 1. 插件能做什么

| 能力 | 说明 |
| --- | --- |
| 监听专注生命周期 | 空间开始 / 结束、每秒倒计时、守护进程拦截、宿主设置变化 |
| 记自己的数据 | `api.get_setting` / `api.set_setting`，落到插件自己的 `settings.json` |
| 发通知 / 写日志 | `api.notify`、`api.log`（写进宿主统一日志） |
| 向宿主发信号 | `api.emit_signal`，宿主可在设置页 toast 或以后接自己的 UI |
| 贡献 UI | 导航入口（`api.register_nav_item`）与全屏遮罩组件（`api.register_widget`） |
| 展示状态 | `api.set_ui_state({...})`，插件页展示插件上报的状态 |
| 查询宿主信息 | `api.host_version()` |

插件不应该自己起常驻线程或 while 循环——钩子都在宿主主线程里按事件调用，
插件只做「收到事件 → 快速处理」。0.1 仍不支持修改宿主设置、主动操作宿主会话。

## 2. 插件目录与扫描顺序

```text
%APPDATA%\ShenQing\plugins\
└─ com.example.my_plugin\
   ├─ plugin.json          # 清单（必须）
   ├─ main.py              # 入口（默认，可在 entry 里改）
   ├─ README.md            # 可选
   └─ lib.py               # 可选，main.py 可 import 同目录模块
```

宿主按下面顺序扫描，**同一 id 只保留优先级最高的那一份**：

| 优先级 | 目录 | 说明 |
| --- | --- | --- |
| 1 | `SHENQING_PLUGINS_DIR` 环境变量 | 覆盖用户插件目录；可以用 `;` 分隔多个目录 |
| 2 | `%APPDATA%\ShenQing\plugins` | 用户安装目录（默认） |
| 3 | `<仓库根>/plugins` | 开发期目录，仅源码环境存在 |
| 4 | `shenqing/plugins/builtin` | 内置示例插件（随程序分发，始终可用） |

PowerShell 里临时指到自己的开发目录：

```powershell
$env:SHENQING_PLUGINS_DIR = "D:\shenqing-plugins"
python run.py
```

注意：

- 只有「直接包含 `plugin.json` 的子目录」才算插件，嵌套目录不会被递归扫描；
- 插件代码目录与数据目录分开：数据在 `%APPDATA%\ShenQing\plugin_data\<插件 id>\`，
  升级 / 重装 / 删除插件代码都不会丢数据；
- 内置示例插件是**直接内置加载**的，不会复制到 appdata；想改它们请复制到
  `%APPDATA%\ShenQing\plugins` 下改，同 id 时用户目录优先。

## 3. plugin.json 字段

| 字段 | 必填 | 类型 | 说明 |
| --- | --- | --- | --- |
| `id` | 是 | string | 唯一 id，建议反向域名，如 `com.example.hello`；只允许字母、数字、点、下划线、短横线，最长 128 |
| `name` | 是 | string | 显示名（设置页插件列表） |
| `version` | 是 | string | 插件版本，建议语义化版本，如 `1.0.0` |
| `api_version` | 是 | string | 依赖的插件 API 版本，如 `0.1`；主版本必须与宿主一致 |
| `entry` | 是 | string | 入口文件相对路径，必须是插件目录内的 `.py`，默认 `main.py` |
| `author` | 否 | string | 作者 |
| `description` | 否 | string | 一句话说明，显示在插件列表 |
| `homepage` | 否 | string | 项目主页 |
| `icon` | 否 | string | 插件图标相对路径，如 `icon.png`（建议 PNG / SVG，插件目录内） |
| `default_enabled` | 否 | bool | 默认 `true`；`false` = 首次安装默认停用，用户手动启用后不会被再次自动关掉 |

其余未知字段会被保留（`PluginManifest.extra`），不会报错。完整 JSON Schema 见
[`sdk/plugin.schema.json`](../sdk/plugin.schema.json)，校验命令见第 9 节。最小示例：

```json
{
  "id": "com.example.hello",
  "name": "你好",
  "version": "1.0.0",
  "api_version": "0.1",
  "entry": "main.py",
  "author": "你的名字",
  "description": "最小插件"
}
```

## 4. 入口类与生命周期钩子

入口模块（`main.py`）顶层必须定义名为 `Plugin` 的类，继承 `PluginBase`：

```python
from shenqing.plugins.api import PluginAPI, PluginBase


class Plugin(PluginBase):
    ...
```

宿主会 `Plugin()` 实例化它，然后按事件调用钩子。钩子全部默认空实现，按需覆写：

| 钩子 | 触发时机 | 参数 | 线程 |
| --- | --- | --- | --- |
| `on_load(api)` | 插件被加载 / 启用时，仅一次 | `PluginAPI` | 主线程 |
| `on_unload()` | 停用、热重载前、程序退出前 | — | 主线程 |
| `on_session_start(space)` | 开始一段专注 | `space` 空间字典 | 主线程 |
| `on_session_end(summary)` | 一段专注结束（自然结束或提前结束） | `summary` 会话摘要 | 主线程 |
| `on_process_blocked(exe)` | 守护进程结束一个干扰程序 | `exe` 进程名，如 `game.exe` | 主线程 |
| `on_tick(remaining_seconds)` | 专注中每秒一次 | 剩余秒数 `int` | 主线程 |
| `on_settings_changed(key, value)` | 宿主设置项变化 | 设置键 / 值 | 主线程 |

### 参数结构

`space`（空间字典，宿主 `SpaceManager` 的字段）：

```json
{
  "id": "sp_1729abcd",
  "name": "工作学习",
  "minutes": 45,
  "atmosphere": "秩序",
  "allowed_apps": ["wechat.exe"],
  "super": false
}
```

`summary`（会话摘要）推荐字段，插件应按「字段缺失也不崩」来写：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `space_id` | str | 空间 id（宿主会尽量带上） |
| `space_name` | str | 空间名 |
| `space` | str | 旧字段，等同空间名（兼容用） |
| `minutes` | float | 实际专注分钟数 |
| `planned_minutes` | int | 计划时长（可选） |
| `completed` | bool | 是否自然完成（提前结束为 `false`） |
| `pauses` | int | 暂停次数 |
| `started_at` / `ended_at` | str | ISO 时间（可选） |

> 当前宿主会传 `space` / `minutes` / `completed` / `pauses`；
> 取名字时建议 `summary.get("space_name") or summary.get("space")`。

### 编写约定

- 钩子里**不要**阻塞（sleep、长循环、大量 IO）：`on_tick` 每秒都会调用；
- **不要**自己起线程 / while 循环，也不要从子线程碰 Qt 对象；
- 钩子里抛出的任何异常都会被宿主捕获写日志，不会拖垮主程序，但你的逻辑会中断；
- `on_load` 抛异常时插件会记为 `error` 状态且不进入加载态，可修复后重新启用。

## 5. PluginAPI

`on_load` 收到的对象，所有方法都会自己吞异常，可安全调用：

| 方法 | 返回 | 说明 |
| --- | --- | --- |
| `log(message)` | — | 写一条插件日志（logger `shenqing.plugins.<插件 id>`，级别 INFO） |
| `get_setting(key, default=None)` | Any | 读插件设置，不存在返回 `default`；返回的是深拷贝 |
| `set_setting(key, value)` | bool | 写插件设置并**立即落盘**；value 必须可 JSON 序列化，成功返回 `True` |
| `notify(title, body)` | — | 弹一条系统通知；托盘不可用时只写日志 |
| `emit_signal(name, payload=None)` | — | 向宿主发信号，宿主通过 `manager.add_signal_listener` 订阅 |
| `set_ui_state(state)` | bool | 把插件想让宿主展示的状态交给宿主（JSON 可序列化）；设置页「插件」列表会在该行下面显示 `state.summary` |
| `host_version()` | str | 宿主版本号，如 `0.1.0`（与插件 API 版本不是一回事） |
| `register_nav_item(item_id, title, icon_name="", qml_relative_path=None, icon="")` | bool | 注册导航入口；QML 必须在本插件目录内，留空表示只跳插件卡片；`icon` 是 `icon_name` 的兼容别名 |
| `register_widget(widget_id, title, qml_relative_path, anchor="topRight", width=280, height=160)` | bool | 注册全屏遮罩组件；九宫格锚点，尺寸吸附到 80-1920 × 40-1080 |
| `plugin_id` / `data_dir` / `settings_path` | str / Path | 只读信息，调试时可直接打开 settings.json |
| `register_nav_page(title, path)` | bool | 旧预留名，0.1 请改用 `register_nav_item`；调用返回 `False` 并记警告 |

`set_ui_state` 示例（首个真实插件：`com.shenqing.tomatodo`，源码在 `F:\个人软件开发\深清插件开发`）：

```python
class Plugin(PluginBase):
    def on_load(self, api: PluginAPI) -> None:
        api.set_ui_state({
            "summary": "今日番茄 2 个 · 50 分钟",
            "tomatodo": {"todayCount": 2, "todayMinutes": 50},
        })
```

宿主收到后会写进插件记录并通过 `pluginsChanged` 刷新 UI；插件状态只用于展示，宿主不会回传。

插件设置文件：`%APPDATA%\ShenQing\plugin_data\<插件 id>\settings.json`。
写入是「临时文件 + 原子替换」，同一进程内用锁保护；但**没有跨进程锁**，
不要把同一个插件同时开两份。

宿主侧订阅插件信号（给 bridge / 设置页用）：

```python
manager.add_signal_listener(lambda plugin_id, name, payload: ...)
manager.remove_signal_listener(callback)
```

### 5.1 UI 贡献：导航入口与遮罩组件

插件在 `on_load` 里注册；宿主通过 `manager.list_nav_items()` / `manager.list_widgets()`
拿到扁平的绝对路径列表，`manager.list_plugins()` 的每条记录也带
`navItems` / `widgets` / `state` 字段。停用 / 重载时注册数据清空，
重新启用后由 `on_load` 重新注册。

```python
api.register_nav_item(
    "home", "我的插件", icon_name="ic_fluent_apps_24_regular",
    qml_relative_path="qml/Main.qml",   # 可空：空则入口只跳插件卡片
)
api.register_widget(
    "countdown", "专注倒计时", "qml/Widget.qml",
    anchor="topRight", width=280, height=160,
)
api.set_ui_state({"summary": "专注中 12:34", "remaining": 754})
```

扁平结构：

- 导航入口：`[{pluginId, itemId, title, icon, qmlPath}]`，`qmlPath` 为空字符串表示无页面；
- 遮罩组件：`[{pluginId, itemId, title, icon, qmlPath, anchor, width, height}]`；
- 锚点：`topLeft` / `topCenter` / `topRight` / `centerLeft` / `center` /
  `centerRight` / `bottomLeft` / `bottomCenter` / `bottomRight`；
- 注册失败（路径越界 / 文件不存在 / 同插件 id 重复 / anchor 非法）返回 `False` 并写日志，
  不影响其它注册。

## 6. 最小插件示例（20 行以内）

`plugin.json` 见第 3 节；`main.py`：

```python
from shenqing.plugins.api import PluginAPI, PluginBase


class Plugin(PluginBase):
    def on_load(self, api: PluginAPI) -> None:
        self.api = api
        api.log("hello 插件已加载")
        api.notify("深清", "hello 插件已加载")

    def on_session_end(self, summary: dict) -> None:
        times = int(self.api.get_setting("count", 0)) + 1
        self.api.set_setting("count", times)
        self.api.set_setting("last_minutes", summary.get("minutes", 0))
```

## 7. 安装 / 启用 / 停用 / 热重载

1. 把插件目录（含 `plugin.json`）放进 `%APPDATA%\ShenQing\plugins\`；
2. 重启深清，或打开「设置 → 插件」点「重新加载插件」（内部调用 `manager.reload()`）；
3. 已加载的插件默认启用；启用状态保存在宿主 `settings.json` 的 `disabled_plugins` 数组里；
4. 停用插件：先调 `on_unload`，再把插件模块从 `sys.modules` 清掉，插件设置与数据保留；
5. 重新启用：重新 import、重新调用 `on_load`；
6. 坏插件（清单错 / 入口缺失 / 导入或 `on_load` 抛异常）只影响自己：
   插件列表里 `error` 字段给出原因，其余插件照常运行；
7. `default_enabled: false` 的插件首次安装会自动停用（写进 `disabled_plugins`，
   同时把 id 记进 `plugin_defaults_applied`）；用户手动启用后会从 `disabled_plugins`
   移除，之后启动 / 重载都不会再被自动关掉。

## 9. 调试

- **日志**：`%APPDATA%\ShenQing\logs\app.log`（1 MB 轮转，保留 3 份）；
  logger 名 `shenqing.plugins` / `shenqing.plugins.<插件 id>`，带 traceback；
- **插件文件名与行号**会出现在异常日志里，直接按 traceback 定位；
- **自测**：

  ```powershell
  cd 深清
  $env:PYTHONPATH = "src"
  python -m shenqing.plugins._selftest
  ```

  自测会临时造插件、跑加载 / 分发 / 注册 / 停用 / 重载 / validate，退出码 0 表示全部通过；
- **校验插件目录**：

  ```powershell
  cd 深清
  $env:PYTHONPATH = "src"
  python -m shenqing.plugins.validate "$env:APPDATA\ShenQing\plugins\com.example.hello"
  python -m shenqing.plugins.validate <插件目录> --json
  ```

  输出清单是否合法、API 版本是否兼容、entry / icon 是否存在；退出码 0 = 通过；
- **不要**在插件里用 `print` 调试（GUI 打包后没有控制台），用 `api.log`。

### 异常隔离规则

| 阶段 | 出问题时 |
| --- | --- |
| 扫描 / 解析 plugin.json | 记 `error`（清单无效），继续扫描其它插件 |
| import 入口模块 / 实例化 / on_load | 记 `error`（加载失败），清理已导入模块，插件不进入加载态 |
| 事件钩子（session_start 等） | 记异常日志，跳过该插件本次事件，继续分发给其它插件 |
| on_unload | 记异常日志，仍继续清理模块 |
| 设置读写 / 通知 / 发信号 | 记日志并返回默认值 / `False`，绝不向宿主抛异常 |

## 10. 版本兼容规则

- 宿主常量 `PLUGIN_API_VERSION = "0.1"`，插件清单写 `"api_version": "0.1"`；
- 兼容判断**只看主版本**：宿主 `0.x` 可以加载 `api_version` 为 `0.1` / `0.2` 的插件；
  `"1.0"` 会被判为不兼容，插件列表显示 `error`，不会执行代码；
- 新增 API 时只加不改（同一主版本内保持向后兼容）；
- 升级主版本意味着可能破坏兼容，旧插件会被标记不兼容，需要作者适配；
- `api.host_version()` 返回的是宿主产品版本（如 `0.1.0`），只适合展示 / 日志，
  **不要**用它做兼容判断，用 `api_version`。

## 11. 安全提示

- 插件是**本地 Python 代码**，与宿主同进程、同权限运行：能读写文件、访问网络、
  调 Win32 API、操作注册表。**安装插件 = 信任它**，宿主没有沙箱也没有签名校验；
- 只装来源可信的插件，安装前先读 `main.py` 和同目录的其它 `.py`；
- 不要把密码、token 写进插件目录：`plugin_data` 里的 `settings.json` 是明文 JSON；
- 插件在宿主主线程执行，死循环 / 阻塞调用会卡住整个界面；
- 卸载插件不会删除 `plugin_data`，需要彻底清理请手动删目录；
- 宿主不会自动下载或更新插件。

## 12. 宿主接线（给 bridge / app 开发者）

```python
from shenqing.plugins import PluginManager

manager = PluginManager(settings)                  # 启动一次即可
# 可选：复用宿主托盘的通知实现；不传则用内部兜底托盘
manager.set_notifier(tray.message)

manager.dispatch("session_start", space_view)      # 开始专注（space 字典）
manager.dispatch("session_end", summary)           # 结束（建议带 space_id / space_name）
manager.dispatch("tick", remaining_seconds)        # 每秒
manager.dispatch("process_blocked", exe_name)      # 守护拦截
manager.dispatch("settings_changed", key, value)   # 任意设置项变化

manager.list_plugins()        # 每条带 iconPath / state / navItems / widgets
manager.list_nav_items()      # [{pluginId, itemId, title, icon, qmlPath}]
manager.list_widgets()        # [{pluginId, itemId, title, icon, qmlPath, anchor, width, height}]
manager.set_enabled(plugin_id, False)   # 启用 / 停用，落盘 disabled_plugins
manager.reload()              # 重扫目录 + 全部重载
manager.get_plugin(plugin_id) # 已加载的插件实例（如 focus_stats.get_summary()）
```

约定：

- `dispatch` 只认第 4 节列出的 5 个事件名，未知事件只记警告；
- 所有方法都在主线程调用，内部用 `RLock` 保护；
- `summary` 目前由 bridge 组装，建议补上 `space_id` / `space_name` 两个键，
  这样 `focus_stats` 能按 id 而不是名字累计；
- QML 侧已有 `App.plugins` / `App.setPluginEnabled(id, bool)` / `App.restartPlugins()`，
  bridge 直接转发到 `list_plugins` / `set_enabled` / `reload` 即可；
- 插件 `set_ui_state` 时宿主可收到回调：
  `PluginManager(settings, state_listener=lambda plugin_id, state: ...)`，
  bridge 用它 emit `pluginsChanged`；导航入口 / 遮罩组件分别用
  `list_nav_items()` / `list_widgets()` 取，`qmlPath` 可直接交给 QML `Loader.source`。

## 13. 打包注意

内置示例插件是数据文件，打包时必须一起收进去：

- `pyproject.toml` 的 `[tool.setuptools.package-data]` 增加：

  ```toml
  [tool.setuptools.package-data]
  shenqing = [
      "qml/**/*.qml",
      "plugins/builtin/**/*.json",
      "plugins/builtin/**/*.py",
      "plugins/builtin/**/*.qml",
      "plugins/builtin/**/*.md",
  ]
  ```

- PyInstaller 的 `packaging/ShenQing.spec` 需要把 `src/shenqing/plugins/builtin`
  整个目录收进 `datas`（或用 `Tree` / `--add-data`）；
- 打包后如果内置示例缺失，插件系统仍能运行（只是少了内置示例），
  启动日志里会有「插件目录」相关记录；
- `sdk/` 与 `templates/` 是仓库开发资料，不随程序打包。

## 15. 手机端 mobile 元数据（深清 0.18+ / 手机端 v1）

插件可以在 `plugin.json` 里声明一个只读的 `mobile` 对象，供「AI 沟通」桥接插件与 Android 原生手机端展示；手机端**不会执行**插件 Python/QML。

```json
"mobile": {
  "summary": "番茄ToDo 数据互通 · 深清专注历史",
  "metrics": [
    {"key": "today_sessions", "label": "今日专注", "source": "settings.history", "aggregate": "today_count", "unit": "次"}
  ]
}
```

- `summary`：一句话，手机插件页显示；
- `metrics`：手机只读指标；`source=settings.<key>` 从插件自己的 settings.json 读取；
- `aggregate`：`today_count` / `today_minutes` / `count`（对列表字段聚合）；
- 也可用 `value` 给静态值；
- 手机端通过 `GET /shenqing/v1/plugins` 读取解析后的 `value`，不执行插件代码；
- 主题包放在插件目录 `themes/*.sqtheme` 时，桥接 `/themes` 会一并列出。
